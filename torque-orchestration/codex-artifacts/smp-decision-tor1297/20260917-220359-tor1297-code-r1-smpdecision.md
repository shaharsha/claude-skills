### 1. Renderer checks only the longest marked trace

`authored_pages/_recipe/as_of.py:1620-1642` · **high** · spec-violation · confidence 0.99

**Evidence.** The renderer validates only the pooled maximum: `to = rc.get("projected_to")` followed by `if not _beyond_edge(str(to), tg, value, grain)`. The resolver instead checks every member of `census["marked"]`, but records only `projected_to` as the longest trace. Static inference; tests could not be executed.

**Failure scenario.** For an edge of `2026-05`, use two marked traces: one ending `2029-07` and a mis-marked actual ending `2026-05`. `refuse_edge_beyond_rendered` refuses because the second trace is not strictly later. A current-rule JSON record with nonzero counts and `projected_to: "2029-07"` passes `rendered_check_problem`, so `build_page.py` can render a record the resolver would refuse.

**Suggested fix.** Record per-trace latest period and grain—or at least the weakest trace selected with the same period ordering—and make `rendered_check_problem` apply `_beyond_edge` to every recorded trace. Add the two-trace resolver-versus-renderer test.

### 2. No-period verdict accepts a record reporting excluded traces

`authored_pages/_recipe/as_of.py:1600-1644` · **medium** · spec-violation · confidence 0.98

**Evidence.** The contradiction check only rejects `no-period-axis` when `periods_before_exclusion > 0`; it ignores `excluded_traces`. The later branch then unconditionally returns `None` for `no-period-axis`. Static inference; tests could not be executed.

**Failure scenario.** A current-rule record with `verdict: "no-period-axis"`, `periods_before_exclusion: 0`, `excluded_traces: 1`, `periods_seen: 0`, and `latest_rendered: null` passes the renderer even though it explicitly reports that a trace was excluded. Such a record violates the invariant that projection exclusion must never produce `no-period-axis`.

**Suggested fix.** For `no-period-axis`, require both exclusion counts to be zero, `periods_seen == 0`, and `latest_rendered is None`; otherwise refuse the record.
