## Findings

### 1. Forecast uncertainty bands fill down to zero

`authored_pages/smp_forecast/charts.js:90-99` · **high** · correctness · confidence 0.99

**Evidence.** `mk()` does not forward `fill_to`, while the lower-bound area calls at lines 142, 196-197, and 238-248 omit `fill_to: 'previous'`. The builder uses `fill="tonexty"` for these six traces, and the chart compiler translates that to `fill_to: 'previous'`. Without it, ChartView renders an ordinary area against the baseline.

**Failure scenario.** Open the default real-client forecast page. The runoff band, book milestone band, and four new-product milestone bands use lower-bound area traces without `fill_to`. Readers see each uncertainty region extend from its lower curve to zero instead of occupying only the interval between upper and lower curves, materially overstating the visual uncertainty. This divergence is also absent from the README's purportedly complete difference list.

**Suggested fix.** Forward `fill_to` through `mk()` and set `fill_to: 'previous'` on every authored lower-bound trace corresponding to builder `tonexty`. Extend parity/binding coverage to compare this field.

### 2. Simulator drops two decision reference lines

`authored_pages/smp_simulator/charts.js:186-229` · **high** · correctness · confidence 0.99

**Evidence.** `mechanicsSpec()` and `dispersionSpec()` define only series. The builder adds a committed-facility reference line in `api/services/smp/loan_simulator.py:299-301` and a break-even reference line at lines 335-337. Compiling the retained payload produces those reference-line contracts, but neither appears in the authored specs or README difference list.

**Failure scenario.** Load the simulator at its defaults or recompute with another facility value. Readers see a chart titled around two ceilings without the committed-facility ceiling, and the dispersion chart without its 1.0 break-even benchmark. The decision charts therefore omit the principal thresholds needed to interpret them.

**Suggested fix.** Add both reference lines. Resolve the mechanics line from the current facility control on every recompute; keep break-even at 1.0. Add parity assertions and declare any intentional remaining divergence in the README.

### 3. Partial recomputes leave the previous scenario visible

`authored_pages/smp_simulator/charts.js:631-683` · **medium** · correctness · confidence 0.97

KPIs change to placeholders, but the prior scenario's narratives, tables, and charts remain on screen because the authored page has no `sim-empty` surface and never clears absent components. The page displays mutually inconsistent old and new states.

**Suggested fix.** Fail closed when the returned surface is incomplete: clear or hide all scenario-dependent regions and render the returned empty/error state. For conditional sections, explicitly remove or hide components absent from the new payload.
