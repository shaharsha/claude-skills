## The domain invariant that matters most

Raw client files are immutable evidence in an S3 vault. Every read must address the **recorded `VersionId`** captured at seal time, never a bare key — a presigned PUT can land after a seal, so a bare-key read can return bytes nothing verified. `upload_sessions.state` (`open|sealing|sealed|failed`) is the schema's declared single source of truth for "may this run be analysed".
