## Intent

### Goal

The page's intro paragraph made a categorical claim about where the page's numbers come from. It read:

> "...every figure is computed from the LR cohort tables, and the controls below affect only the
> plan-decomposition figures and their break-even cards."

The acquisition-spend bars on this page are drawn from a table named `lr_spend`, which is
month-keyed, not cohort-keyed. So the categorical clause excluded a table the page actually
draws from. The change rewords that clause to:

> "...every figure is computed from the LR cohort and spend tables, and ..."

Only the SOURCE half of the sentence was intended to move. The control clause after it
("and the controls below affect only the plan-decomposition figures and their break-even cards")
was intended to stay byte-identical.

### Requirements and invariants

1. **Text parity between the two venues is an invariant of this repo.** The authored page carries
   `data-src` attributes marking strings as `verbatim` copies of the builder's strings. A string
   marked verbatim must match the builder's string. If you find any way this change breaks that
   for the intro paragraph — or for any other `verbatim` string on the page — that is a defect.
2. The change must not alter any number, any chart, any control, or any section ordering.
3. No caption golden files were updated, on the stated grounds that the edited element is a
   `text_section` rather than a caption. Check whether that grounds holds.

### Runtime context

- The scope was deliberately kept to this one page. Other pages and other builders that carry
