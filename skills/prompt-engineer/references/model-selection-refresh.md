# Refreshing the Artificial Analysis data in `model-selection.md`

For whoever updates the table in `model-selection.md` or needs a figure newer than its snapshot. Not needed to choose a model: read `model-selection.md` for that.

- **The legacy `/api/v2/data/*` endpoints were retired on Nov 4 2026** (they now return 410 Gone). Use **`GET https://artificialanalysis.ai/api/v2/language/models/free`** (header `x-api-key`, same key): it is paginated (`?page=N`, 200 variants per page, `pagination.has_more`; 726 variants on 2026-11-07, 739 on 2026-11-13, 742 on 2026-11-17, 758 on 2026-11-18, 766 on 2026-11-26), reports `intelligence_index_version` (5), and gives per model and effort the intelligence index, `artificial_analysis_intelligence_index_cost.cost_per_task.total_cost`, per-token prices, and two speed blocks: `performance` (medians, being retired) and `performance_v3` (`mean_output_tokens_per_second`, `mean_time_to_first_answer_token_seconds`), which the table's tok/s column uses. Its cost and intelligence values matched the page data exactly. `/api/v2/language/models` (Pro) has more fields. **The `performance` block returns null from Dec 10 2026.** `performance_v3` follows AA's Performance v3 method (version 3.0.0, Nov 3 2026; `artificialanalysis.ai/methodology/performance-benchmarking`): a workload's value is the average of its run medians over 5 days and the headline figure averages the workloads, where the old figure was the median of the 10K-token workload over 72 hours. The two differ in both directions (Nov 17: Hydrogen `high` 179 vs 204, Fable 5.2 `high` 111 vs 75). **The table moved to `performance_v3` on 2026-11-17, all 60 rows from one pull** - refresh it the same way, never row by row: AA re-measures every 6 hours, and a row's speed can move several percent within a day (adding GPT-6.2 on Nov 18 and Neon on Nov 26 meant re-pulling every row; the table has 64 since Nov 26). **The API and the model pages can disagree on price:** on Nov 18 the API priced Carbon at $4 / $20 ($6.59-7.76 per task) while its pages still used $2 / $10 ($4.68-5.48); on Nov 26 both used $4 / $20 for Carbon and Argon - compare `pricing` and cost per task between the two before writing a cost. **Cost per task also moves with AA's measured cache hit rate** (its methodology page: "live measurements of the model's typical cache hit rate"), so a cost can change between pulls with the same prices and tokens (Gemini 3.8 Flash `high`: $7.77 on Nov 18, $3.02 on Nov 26). Other changes in AA's API notes: the index is v5.0.2 (patch bumps don't show in `intelligence_index_version`, and they move scores: 28 of 60 rows changed by 0.1-0.3 points between Nov 18 and Nov 26); the coding and agentic index fields are retired (always null) and six capability indexes are new (finance and accounting, strategy and ops, legal, healthcare and medical, engineering, economics); the v1 API (`/api/data/v1/*`) returns 410 from Dec 16 2026.
- **Time per task and hallucination rate** (and output tokens per task and sub-benchmark scores) are still only in the AA **model pages** (e.g. `artificialanalysis.ai/models/gemini-4-argon`) as Next.js flight data - decode the `self.__next_f.push([1,"…"])` strings and JSON-decode each `{"id":…,"slug":…}` object, keyed by `id` (effort variants share a release slug prefix); fields `name`, `effort.label`, `intelligenceIndex`, `intelligenceIndexCostPerTask.cost.total`, `intelligenceIndexTimePerTask` (output tokens ÷ output speed, benchmark-weighted - an estimate, not measured wall-clock; the speed is the API's `performance_v3` mean - on Nov 17 tokens ÷ time matched it on all 59 rows that have a time, e.g. Hydrogen `high`: 84,978 output tokens ÷ 474 s = 179 tok/s; on Nov 18 six rows differed, five by under 1% and GPT-6.2 Astra `medium` by 8%; on Nov 26 all 63 rows with a time matched), `omniscienceHallucinationRate`, `intelligenceIndexOutputTokensPerTask`. **Not every page carries every variant:** on 2026-11-07 some pages (Argon, Kimi K3.1 Pro, Flash-Lite) embedded all 726, others only the ~28 chart defaults - check the count and try another page if it's short. On 2026-11-13 the Carbon and Hydrogen pages carried only their own default variant; each effort has its own page (`/models/gemini-4-hydrogen-high`, `-medium`, `-low`), which carries that variant's metrics (on Nov 17 each Gemini 4 page carried all nine Gemini 4 variants, including the new `gemini-4-argon-medium`). Fetching one page per row always worked on Nov 17: every variant's own page carried that variant, and the API's `slug` field is the page slug (`claude-fable-5-2-high`, `gpt-6-1-terra-non-reasoning`; usually no suffix for the top effort). Also check the API's `pricing` fields: AA switched Carbon and Argon from list to intro prices between the Nov 7 and Nov 13 pulls, which moved their cost per task.
